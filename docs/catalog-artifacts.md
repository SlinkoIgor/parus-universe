# Архивы каталогов

Код, небольшие исходные таблицы, проверенные дополнения, атрибуция и версии
данных хранятся в Git. Пространственные JSON-файлы, индексы проекций,
предварительно рассчитанные направления DSS и дерево иерархии распространяются
отдельным `tar.gz` в GitHub Releases. Фотографии DSS в архив не входят.

`data-tools/catalog-artifact.json` фиксирует точный URL, SHA-256 и размер
архива, а также пути, размеры и SHA-256 всех его файлов. Имя архива и тег
релиза включают первые 16 знаков SHA-256 самого архива. Обновление каталога
создаёт новую версию; существующий релиз не перезаписывается.

## Установка

Python 3.9+, без сторонних библиотек:

```sh
python3 data-tools/catalog-artifacts.py install
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Установщик проверяет архив целиком, распаковывает его во временную папку,
проверяет каждый файл и лишь затем публикует каталоги. Указатели `current.json`
обновляются после полных версионных папок. Ошибка публикации восстанавливает
предыдущие файлы. Другие локальные версии каталогов, код и сохранения не удаляются.
Повторная установка той же версии проверяет локальную отметку и наличие/размеры
файлов; полная проверка их содержимого выполняется отдельно:

```sh
python3 data-tools/catalog-artifacts.py check
```

Если проверка обнаружила повреждение, `install --force` заново установит
закреплённую версию, включая случай изменения файла без изменения его размера.

Архив можно перенести на другую машину и установить без сети:

```sh
python3 data-tools/catalog-artifacts.py install --archive /absolute/path/parus-catalogs-VERSION.tar.gz
```

## Новая версия данных

Научная пересборка остаётся отдельной задачей: ей нужны замороженные исходные
снимки HYG/OpenNGC/ATNF в `data-tools/raw/`, остальные опубликованные входные
таблицы и генераторы. Скачивание свежей версии исходника не гарантирует прежних
результатов. Имена, орбиты, поправки, источники и ограничения сохраняются в Git.

После пересборки и проверок из `README-AGENT.md`:

```sh
python3 data-tools/catalog-artifacts.py build --output-dir /absolute/path/artifacts
```

Команда включает только актуальные папки из пяти `current.json`, текущую
версию DSS из `sky-dss-data.js`, дерево иерархии и атрибуцию. Она обновляет
манифест в Git и создаёт архив вне репозитория. Нумерованные копии iCloud и
прежние сборки исключаются. Заголовки архива не зависят от времени и владельца.

Опубликуйте полученный файл в GitHub Release репозитория
`SlinkoIgor/parus-universe` с тегом `catalog-data-<revision>` из манифеста.
Проверьте установку по опубликованному URL в пустую папку через `--target`,
затем сохраните изменения кода, указателей и манифеста в одном коммите.
Архив, распакованные файлы и `.catalog-artifact.json` в `dist` не коммитятся.

Проверки установщика: `python3 data-tools/test_catalog_artifacts.py`.
Ранее закоммиченные каталоги остаются в прежней истории Git; перенос новых
версий в Releases не переписывает и не очищает эту историю.
