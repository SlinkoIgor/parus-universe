# Оптимизация отрисовки · 06.11.2026

Работа начата после завершения двух соседних задач. Основа — фактическая
локальная рабочая копия после `3636cdfb`, включая прежние незакоммиченные
изменения. Публикации и коммита этой оптимизации не было.

## Изменения

В одном синхронном проходе отрисовки переиспользуются индекс объектов,
результаты прозрачности и классификация «точка или контур». Индекс сохраняет
первую запись каждого ID и прежний приоритет частных исторических записей
полёта. Вне прохода действует прежний поиск, поэтому добавления, замены,
старые сохранения и смена каталожных ссылок не получают устаревшие результаты.

Проход начинается после симуляции, камеры и принятия потоковых слоёв;
заканчивается до обновления UI и записи сохранения. `finally` освобождает
все три кэша даже при исключении. Прозрачность различает масштаб и ширину
экрана; следующий кадр снова читает актуальные данные. Кэши не сериализуются.

Фоновые точки отбрасываются из прохода переднего плана до подготовки геометрии.
Выбранная точка, стоянка и прежний sparse-режим сохраняют свои исключения.
Фоновый проход проверяет видимость до вычисления геометрии. Формулы физики,
точность орбит, научные данные, пороги видимости и частота кадров не менялись.

## Замеры

Chrome 157.0.8103.39, отдельный профиль. Desktop — 1440 × 1000, DPR 1;
mobile — 390 × 844, DPR 2. Измеряется время выполнения JavaScript внутри
кадра, а не интервал обновления экрана, общая загрузка CPU или старт страницы.

Основное сравнение чередует прежний и новый проходы в одном браузере на
одних загруженных объектах и одинаковом исходном физическом состоянии.
Во время каждого измерения набор тайлов зафиксирован; физика и UI продолжают
исполняться. По три серии по 60 кадров для каждого варианта, между кадрами
браузер получает настоящий requestAnimationFrame. Таблица — медиана средних
трёх серий. В полёте используется настоящий план Sol → Alpha Centauri,
участок свободного полёта; корабль остаётся в полёте во всех сериях.

| Сценарий | До, мс | После, мс | Сокращение работы кадра |
| --- | ---: | ---: | ---: |
| Ближайшие звёзды · desktop, пауза | 16.65 | 12.16 | 27.0% |
| Галактика · desktop, пауза | 40.81 | 34.60 | 15.2% |
| Полёт · desktop, обычная карта | 24.45 | 19.23 | 21.4% |
| Полёт · mobile, срез | 13.57 | 9.54 | 29.7% |

Отдельные прогоны полной прежней и новой страницы (три серии по 90 кадров,
плюс CPU-профили) охватили семь сцен: пауза у звёзд, Галактика, Вселенная,
обычный/радиальный полёт, мобильный срез и разрешённые орбиты Сириуса.
В них сокращение времени кадра составило 11–27%. Разница с основной таблицей
связана с накопленным набором загруженных галактик после просмотра карты и
условиями отдельных запусков. Эти числа не означают такое же снижение
потребления энергии или ускорение всей игры; тяжёлый вид Галактики всё ещё
может занимать больше 16,7 мс. Сложные орбитальные проекции остаются заметной
частью работы при сильном приближении.
